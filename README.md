# DevCraft Landing

Статичний сайт DevCraft для трафіку з Instagram.

## Що всередині
- UA / RU окремі сторінки
- Telegram: `https://t.me/gryftd`
- Instagram: `https://www.instagram.com/medve._dev/?hl=uk`
- дві комплектації: 10 000 грн / 20 000 грн
- команда з 4 картками та ролями
- місця для 4 фотографій
- responsive mobile design
- без вигаданих відгуків та кейсів

## Фотографії
Покладіть у `assets/`:
- `sasha.jpg`
- `kolganenko.jpg`
- `danil.jpg`
- `vasylchenko.jpg`

Фото автоматично обрізаються через `object-fit: cover`, тому бажано використовувати вертикальні фото, де людина приблизно по пояс.

Поки фото немає, сайт покаже ініціали.

## Деплой
Це звичайний статичний HTML/CSS/JS. Можна завантажити репозиторій у GitHub і підключити до Vercel, Netlify або GitHub Pages.
